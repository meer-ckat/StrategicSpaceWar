# 대사 대본 작성법

파일 하나 = 대본 하나. 파일 이름이 곧 대본 이름이다 (`prologue.json` → `Play("prologue")`).
없는 이름을 부르면 조용히 아무 일도 안 일어난다 — 대사를 안 쓴 사건 때문에 게임이 멈추지 않는다.

## 형식

```json
{
  "defName": "prologue",
  "pickOne": false,
  "cooldown": 0,
  "lines": [
    {
      "message": "Control, we're picking up something. <color=yellow>It's not a distress signal.</color>",
      "author": "PATROL 17",
      "duration": 5,
      "intensity": 0.8,
      "wait": 0
    }
  ]
}
```

**파일 단위**

| 키 | 뜻 | 생략하면 |
|---|---|---|
| `pickOne` | 참이면 `lines` 중 **한 줄만** 고른다 (대본이 아니라 변형 목록) | false |
| `cooldown` | 이 초 안에는 같은 대본이 다시 안 나온다 | 0 (제한 없음) |

**줄 단위 (`lines`)**

| 키 | 뜻 | 생략하면 |
|---|---|---|
| `message` | 대사 본문. `<color=...>` `<b>` `<i>` 사용 가능 | 그 줄은 무시된다 |
| `author` | 대사 아래 작게 붙는 화자. 빈 문자열이면 안 나온다 | 화자 없음 |
| `duration` | 이 줄이 **화면에 머무는** 초 | 4 |
| `intensity` | 등장 충격 세기. 아래 참고 | 1 |
| `wait` | **다음 줄이 나올 때까지의** 초 (`pickOne`이면 안 쓴다) | 자동 (아래 참고) |

`defName`은 기록용이라 파일 이름과 맞춰만 두면 된다. 실제로 찾는 건 파일 이름이다.

## 이야기 대본과 사건 대본

**이야기 대본** (`prologue`, `battle-won`) — `pickOne` 없음. 줄이 순서대로 이어지는 한 장면이다.

**사건 대본** (`detonated-enemy`, `hull-split-ally`) — `pickOne: true` + `cooldown`.
유폭이 한 전투에 스무 번 나는데 매번 같은 문장이면 두 번째부터는 글자가 아니라 벽지다.
줄을 여러 개 써 두면 그중 하나가 나온다. `cooldown`은 필수다 — 유폭·선체 절단은 한 틱에
여러 번 날 수 있고, 없으면 화면이 대사로 덮인다.

## 타이밍 — `duration`과 `wait`은 다른 일을 한다

- `duration` = 이 줄이 얼마나 오래 떠 있나
- `wait` = 다음 줄이 얼마나 빨리 오나

**둘이 다르기 때문에 통신이 겹친다.** `wait`이 `duration`보다 짧으면 앞줄이 아직 떠 있는 채로
다음 줄이 올라오고, 오래된 줄은 위로 밀리며 흐려진다.

`wait`을 0으로 두면 자동으로 **타이핑이 끝나는 시간 + 0.6초**가 된다. 보통은 이걸로 충분하다.

- 타이핑 속도는 초당 42자. 100자짜리 대사 ≈ 2.4초.
- `duration`이 타이핑 시간보다 짧으면 자동으로 늘어난다 (타이핑 시간 + 0.5초가 하한).
- 뜸을 들이고 싶으면 `wait`을 크게 (`"wait": 3`).
- 몰아치게 하려면 `wait`을 작게 (`"wait": 0.3`).
- 화면에는 동시에 최대 5줄. 넘으면 오래된 줄부터 밀려 나간다.

## `intensity`

등장할 때의 충격 세기. 위치 튐, 떨림, 화자 이름 부풀기가 전부 이 값에 비례한다.

| 값 | 느낌 |
|---|---|
| 0.5 | 시스템 로그, 배경 안내 |
| 0.8 ~ 1.0 | 평범한 교신 |
| 1.4 이상 | **화면 전체가 흔들린다.** 결정적인 대사에만 |
| 2.0 | 신호 두절, 격침 보고 |

1.4를 남발하면 아무것도 안 흔든 것과 같아진다.

## 치환

`{0}`은 게임이 넘기는 값으로 바뀐다. 함선 이름 같은 것.

```json
{ "message": "<color=red>{0}</color> not answering.", "author": "COMMS", "duration": 3 }
```

## 게임이 알아서 부르는 이름

아래 이름으로 파일을 만들어 두면 해당 사건에 자동으로 재생된다. 없으면 그 사건엔 대사가 없다.

사건 대본은 **팀별 이름을 먼저 찾고, 없으면 공용으로 내려간다.** `detonated-enemy.json`이
없으면 `detonated.json`을 쓴다. 그래서 팀에 따라 말이 달라져야 하는 사건만 두 벌 쓰면 된다.

| 파일 | 언제 | `{0}` |
|---|---|---|
| `prologue.json` | 시작할 때 (인스펙터 `openingScript`) | — |
| `battle-won.json` | 전투 승리 | — |
| `battle-lost.json` | 전투 패배 | — |
| `ship-finished-{팀}.json` | 함선이 전투불능 | 함선 이름 |
| `detonated-{팀}.json` | 탄약고·원자로 유폭 | 모듈 이름 |
| `hull-split-{팀}.json` | 선체가 갈라져 조각이 떨어짐 | 함선 이름 |
| `crew-lost-{팀}.json` | 승무원 전멸 (전 구역 감압) | 함선 이름 |

`{팀}`은 `enemy` / `ally` / `neutral`. 접미사 없는 파일이 공용 폴백이다.

## 고칠 때

대본은 한 번 읽고 캐시된다. 에디터에서 JSON을 고쳤으면 플레이를 다시 시작하거나
`StoryScriptManager.ReloadScripts()`를 부를 것.

## AI에게 그대로 주는 프롬프트

```
SUPERRADIANCE(우주 함선 시뮬레이션 로그라이크)의 대사 JSON을 써라.

형식:
{
  "defName": "<파일이름>",
  "lines": [
    { "message": "...", "author": "...", "duration": 5, "intensity": 1.0, "wait": 0 }
  ]
}

규칙:
- 게임 내 표시 언어는 영어다. message와 author는 **영어로** 써라.
- message: 대사 본문. <color=yellow> <color=red> <color=grey> <b> <i> 사용 가능.
  강조할 구절만 색을 입히고, 한 줄 전체를 칠하지 마라.
- author: 화자 이름. 대문자 호출부호를 쓴다. 함내 배치는
  CAPTAIN / TACTICAL / GUNNERY / ENGINEERING / COMMS / HELM,
  함외는 ATRIA CONTROL / FLEET COMMAND / SYSTEM. 화자가 없으면 빈 문자열.
- duration: 화면에 머무는 초. 짧은 대사 3, 보통 5, 긴 설명 6~7.
- intensity: 0.5 시스템 로그 / 0.8~1.0 평범한 교신 / 1.4 이상은 화면이 흔들리므로
  대본당 두세 줄만 / 2.0 신호 두절 같은 결정적 순간.
- wait: 다음 줄까지의 초. 0이면 자동(타이핑 끝 + 0.6초)이고 앞줄과 자연스럽게 겹친다.
  뜸을 들일 자리만 2~4를 명시하고, 몰아칠 자리는 0.3.
- 한 줄은 120자를 넘기지 마라. 길면 두 줄로 쪼개라.
- 화면에 동시에 5줄까지만 뜬다.

세계관:
아트리아 공화국 대 변경, 12년째 전쟁. 블랙홀 시설을 반사 껍질로 감싸 초복사(superradiance)로
증폭하는 무기가 있고, 그 시설은 원래 공화국 에너지 시설이었으며 무기 설계도 공화국 연구였다.
플레이어는 아트리아 함장이고, 죽으면 다음엔 다른 함장이 온다.
말투는 군용 무전. 짧고, 감정을 억누르고, 설명하지 않는다.

주제: <여기에 무엇에 대한 대본인지 쓴다>
파일 이름: <여기에 파일 이름>
```
