# 수직 슬라이스 계획 — 22노드를 3노드로 (2026-09-13)

`/plan-ceo-review`(SCOPE REDUCTION 자세) 결과물이다. 검토 대상은 `Docs/GDD.md`,
결정은 D1 = A안(수직 슬라이스), D2 = B(프레이밍 먼저, 성능은 그 뒤), D3 = A안 유지(바깥 목소리 정정 반영).

## 0. 왜 자르는가 — 숫자 하나

22노드 런은 **연료로 완주할 수 없다.** 출하된 값으로 곱하면 그대로 나온다.

| | 지금 (60 km) | 슬라이스 (20 km) |
|---|---|---|
| 들판 횡단 거리 | 60.7 km | 19.0 km |
| 횡단 Δv (`drag × 거리`, 속도 무관) | 18,210 m/s | 5,692 m/s |
| 워프 | 6,000 | 6,000 |
| **노드당** | **24,379** | **11,861** |
| Ark 총 Δv (250탱크 × 320,000 ÷ 454.65 t) | 175,960 | 175,960 |
| **갈 수 있는 노드** | **7.2 / 22** | **14.8 / 3** |
| 횡단 시간(주추력 169 m/s) | 6.0분 | 1.9분 |

`TravelCost = drag × 거리 + CruiseSpeed`이고 **어떻게 날아도 같다** — 관성 항해도 같은 값으로 수렴한다.
모델 검증: `CruiseSpeed / drag` = 563 m가 실측 관성 정지 564 m와 맞는다.

## 1. 슬라이스 명세 (바깥 목소리 정정 반영)

```
[타이틀] → [함선 선택] → 장 1 (대본) → 들판 1 (20 km) → 장 2 (엔딩, target) → [결과] → [재시작]
              ✓             ✓              ✓                  ✗                ✗        ✗
```

**오픈섹터는 장과 장 사이에만 생긴다.** `Campaign.Advance`가 `_sector >= sectors.Count - 1`이면
곧장 `ToChapter`로 간다. 그래서 "1장 + 들판 1 + 엔딩"은 장이 **둘**이어야 성립한다.
이것을 몰랐으면 `campaign.json`을 1장으로 자르고 "왜 들판이 안 나오지"로 하루를 썼다.

| # | 바꾸는 것 | 지금 | 슬라이스 | 왜 |
|---|---|---|---|---|
| 1 | `campaign.json` 섹터 | 8 | **2** (장 1 + 엔딩) | 1이면 들판이 0개다 |
| 2 | `OpenSectorGen.LegsPerChapter` | 2 | **1** | 2면 첫 들판 뒤 또 갈림길이 생겨 엔딩에 안 간다 |
| 3 | `FieldLength` / `FieldHalfWidth` | 60,000 / 30,000 | **20,000 / 10,000** | 연료 산수와 2분 횡단 |
| 4 | `MinClusters` / `MaxClusters` | 15 / 25 | **4 / 6** | 20 km에 `ClusterSpacing` 6 km면 5개가 물리적 상한이다. 15는 거짓말이 된다 |
| 5 | 엔딩 섹터 `SpawnDef.target` | 없음 | **true** | 없으면 승리 조건이 "거울 절단"이 아니라 "적 소탕"이 된다 |
| 6 | `OpenSectorGen.Version` | 4 | **5** | 3·4가 바뀌면 옛 런이 다른 우주다. 마이그레이션 없음(설계) |
| 7 | 타이틀·시놉시스 화면 | 없음 | **새로** | GDD §11.2 P0 |
| 8 | 결과 화면 | 없음 | **새로** | `RunCleared()`가 대사 + `Phase.Done`뿐이다 |
| 9 | 재시작 루프 | 없음 | **새로** | 결과 화면에서 다시 시작할 길 |

**난이도 주의**: 템플릿 tier는 `chapter` 인덱스로 오른다(`Pick`의 `want = 1 + chapter/3`).
엔딩을 장 2로 당기면 들판이 tier 1에서만 뽑혀 가장 쉬운 적만 나온다.
슬라이스에서는 `Make`에 넘기는 chapter를 손으로 3~4로 고정한다 — 인덱스가 아니라 값이다.
